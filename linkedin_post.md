# Jiwar | Redefining Luxury Real Estate 🏜️✨

I'm thrilled to unveil **Jiwar**, a production-grade, full-stack real estate platform built for scale, performance, and aesthetic excellence. Tailored specifically for the luxury market, Jiwar delivers an editorial-grade user experience across iOS, Android, and the web.

Unlike typical MVP applications, Jiwar implements a rigorous production architecture designed to impress. Here’s a look under the hood:

🏗 **Robust Tech Stack**
Powered by **React Native** and **Expo**, Jiwar ensures a seamless, native-feeling cross-platform experience. Our bespoke **"Desert Minimal"** design system moves away from generic utility classes, employing centralized design tokens to guarantee perfect alignment with luxury brand identity across all OS paradigms.

🔐 **Zero-Friction Auth & Security**
We integrated **Clerk** for headless authentication flows, seamlessly paired with **Supabase Row Level Security (RLS)**. This combination ensures data integrity and privacy at the database level, with dynamic role-based access for robust admin capabilities (like managing listings directly within the app).

🌐 **Offline-First Resilience & Performance**
With global state gracefully handled by **Zustand**, Jiwar features intelligent query caching for offline-first resilience. Add in performant cartography via OpenStreetMap integrations, and users get a deeply immersive property exploration experience.

From strict unidirectional data flows to robust keyboard avoidance strategies, every detail in Jiwar was crafted to provide a flawless experience for buyers, sellers, and admins alike.
